#### 🛠️ How they're built

- [uv](https://docs.astral.sh/uv/) + [hatchling](https://hatch.pypa.io/) — dependency management and packaging
- [ruff](https://docs.astral.sh/ruff/) + [mypy](https://mypy-lang.org/)/[django-stubs](https://github.com/typeddjango/django-stubs) — lint, format, types
- [pytest](https://pytest.org/) + [pytest-django](https://pytest-django.readthedocs.io/) + [Playwright](https://playwright.dev/) — unit, integration, and real-browser e2e tests
- [vitest](https://vitest.dev/) — JS test suites where a library ships static JS
- [tox](https://tox.wiki/) (via [tox-uv](https://github.com/tox-dev/tox-uv)) — compatibility matrix across supported Python/Django versions
- [pre-commit](https://pre-commit.com/) + GitHub Actions — the same checks locally and in CI
